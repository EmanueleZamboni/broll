# B-ROLL — the free YouTube downloader for video editors

B-ROLL grabs footage, clips, playlists and audio straight from YouTube — built
for editors, not for ripping music. Trim in/out points before you download,
export straight into **ProRes** or **DNxHR**, and get automatic creator-credit
files for every clip.

## Download

**[⬇ Download the latest release](https://github.com/EmanueleZamboni/broll/releases/latest)** — Windows, macOS and Linux.

| Platform | File |
|---|---|
| Windows (installer) | `BROLL-Setup.exe` |
| Windows (portable) | `BROLL-portable.exe` |
| macOS | `BROLL-macOS.dmg` |
| Linux | `BROLL-x86_64.AppImage` |

The app checks for new versions on launch and can update itself.

## Features

- Download single clips or **whole playlists**
- **Trim** in/out points with a J/K/L shuttle preview before downloading
- Export to professional formats — **ProRes, DNxHR**, plus MP4 and audio-only
- Separate download folders for video and audio
- Subtitles (embedded or `.srt` / `.ass` / `.vtt`)
- Real bitrate & resolution shown for every file
- Automatic **creator-credit / attribution** files
- Download from a text file of URLs, or straight from your browser bookmarks

## Please use it responsibly

B-ROLL is a tool. Only download content you have the right to use — your own
uploads, Creative Commons or public-domain footage, or material you have
permission to use. Respect creators and copyright.

## Built on open source

B-ROLL is a GUI built around brilliant open-source projects — it downloads the
tools it needs on first launch:

- [yt-dlp](https://github.com/yt-dlp/yt-dlp) · [FFmpeg](https://ffmpeg.org) · [Deno](https://deno.com) · [Python](https://python.org) · [Pillow](https://python-pillow.org) · Tcl/Tk
